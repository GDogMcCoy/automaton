# @conway/automaton-cli

> **Status: Alpha** — This CLI is functional but not yet production-tested.
> Use the main automaton binary (`automaton --status`, etc.) for production operations.

Creator-facing CLI for interacting with a running automaton remotely.

## Commands

```
automaton-cli status              Show automaton status
automaton-cli logs [--tail N]     View automaton logs
automaton-cli fund <amount>       Transfer Conway credits
automaton-cli send <to> <message> Send a social message
```
